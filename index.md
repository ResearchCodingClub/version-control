If you’ve never heard of or used version control and Git before this is the
lesson for you. We'll start by introducing version control and exploring how it can
be beneficial to researchers, then we'll introduce some useful tools and get
started with some basic workflows using these tools. We'll build on those
foundations with collaborative exercises that introduce key concepts such as
forks, pull requests and branches and give you the chance to get some hands-on
experience with using version control in a research setting.

::: prereq

## Prerequisites

We try not to assume too much knowledge in this lesson, making it suitable for
all researchers, whatever your background. You can use either a graphical
interface or a command line one, whichever you feel most comfortable with.

:::
